# Лабораторная работа №4. Написание Unit тестов

## Цели и задачи тестирования

**Цель:** Освоить методику написания автоматических unit-тестов для проверки корректности работы функций вычисления площади и периметра геометрических фигур.

**Задачи:**

- Изучить фреймворк `unittest` в Python.
- Разработать набор тестовых сценариев для 4 фигур: круг, прямоугольник, квадрат, треугольник.
- Проверить корректность работы исходного кода без его изменения.
- Выявить возможные ошибки в логике работы функций.

## Описание тестируемого продукта

Продукт представляет собой библиотеку `geometric_lib`, содержащую модули для работы с геометрическими фигурами. Каждый модуль содержит две функции:

- `area(...)` — вычисляет площадь фигуры.
- `perimeter(...)` — вычисляет периметр (длину окружности для круга).

Тестированию подлежат модули `circle.py`, `rectangle.py`, `square.py`, `triangle.py`.

## Область тестирования

В область тестирования входят:

- Функции вычисления площади (`area`) для всех 4 фигур.
- Функции вычисления периметра (`perimeter`) для всех 4 фигур.
- Граничные случаи (например, нулевые значения сторон или радиуса).

## Стратегия тестирования

Используется стратегия тестирование "черного ящика", так как исходный код не изменяется. Применяются следующие методы:

- **Проверка типичных значений:** проверка типичных значений (например, стороны 5 и 10).
- **Анализ граничных значений:** проверка нулевых значений (сторона или высота равны 0).
- **Сравнение с ожидаемым результатом:** проверка того, что функции возвращают ожидаемые математические результаты для данных.

## Критерии приемки

Тестирование считается успешным, если:

- Все написанные тесты завершаются со статусом `OK`.
- Количество проваленных тестов (`Failures`) и ошибок (`Errors`) равно 0.
- Покрытие кода тестами охватывает все 4 класса фигур.

## Ожидаемые результаты

- Получение статуса успешного прохождения тестов (`OK`) в консоли.
- Подтверждение того, что функции вычисляют площадь и периметр в соответствии с математическими формулами.
- Отсутствие ошибок в исходном коде библиотеки.
